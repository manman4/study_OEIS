# tiling

ある領域（正方形・階段ポリオミノ・三角形・菱形・六角形）を、辺の長さが整数の図形で敷き詰める方法の数。

- domino（ダイマー模型）は理論がはっきりしているので、別ディレクトリ [domino](../domino/domino.md) にまとめている。
- 特に断りがなければ、回転・鏡映で移り合う敷き詰めも別々に数える。
- 初項は 2026年11月時点の OEIS の値。OFFSET は変更される可能性あり。

## 1. 正方形を正方形・長方形で（単調条件つき）

条件のない基本形は [A045846](https://oeis.org/A045846)（n X n 正方形を整数辺の正方形で敷き詰める）。

「単調」は、各行で左から右へ、各列で下から上へ、大きさが広義単調減少すること。

## 3. 直角二等辺三角形

タイルはどれも直角二等辺三角形。どの三角形を許すかで 3 段階ある。

- (a) 頂点が格子点で、等辺（脚）が座標軸に平行
- (b) 頂点が格子点で、各辺が座標軸または対角線に平行
- (c) 各単位正方形に対角線を 2 本引いてできる小三角形をいくつか合わせたもの

(a) で使えるタイルは (b) でも使え、(b) で使えるタイルは (c) でも使える。よって (a) <= (b) <= (c)。

| 領域 | (a) | (b) | (c) |
| ----- | ----- | ----- | ----- |
| n X n 正方形 | [A400997](https://oeis.org/A400997) | [A401117](https://oeis.org/A401117) | [A402162](https://oeis.org/A402162) |
| 三角形 (0,0), (n,0), (0,n) | [A402198](https://oeis.org/A402198) | [A402199](https://oeis.org/A402199) | [A402200](https://oeis.org/A402200) |

三角形の (b) では「各辺が大きい三角形の辺に平行または垂直」と言い換えられる。
