# Number of divisors of s\*n-t of form s\*k+u

`a(n) = sumdiv(s*n-t, d, d%s==u)`

[sumdiv.md](sumdiv.md) の Sum_{k>=1} ... x^k/(1 - x^(...)) 型の G.f. をもつ数列の一つの系統。

名前・G.f.・OFFSET は OEIS（2026年11月時点）から。データ項は上の PARI の式を直接計算して全件一致を確認済み。

46 件の OEIS の式（%F）は 2026年11月28日時点ですべて確認済み。

## 相方の約数による一致

m = s\*n-t ≡ -t (mod s) の約数 d に対し、m/d も約数。
gcd(u, s) = gcd(t, s) = 1 のとき、d ≡ u ⇔ m/d ≡ u' := -t\*u^(-1) (mod s)。

よって **(t, u) と (t, u') の数列は一致する**（表では `= A......` と書く）。

gcd(t, s) > 1 では u' が s と互いに素でなくなり、逆向きが成り立たないので一致しない（例：4\*n-2 の u = 1 と u' = 2）。

例：7\*n-5 では u = 1 と u' = -5\*1 ≡ 2 が一致する。A363852 は「Number of divisors of 7\*n-5 of form 7\*k+1.」で、%C に「Also number of divisors of 7\*n-5 of form 7\*k+2.」とある。

## 母関数

gcd(u, s) = 1 とする。u' を u\*u' ≡ -t (mod s) をみたす 1 <= u' <= s-1 の数、q = (u\*u' + t)/s（整数）とおくと

```
Sum_{n>=1} a(n)*x^n = Sum_{i,j>=0} x^(s*i*j + u*i + u'*j + q)
                    = Sum_{j>=0} x^(u*j+q)  / (1 - x^(s*j+u'))
                    = Sum_{j>=0} x^(u'*j+q) / (1 - x^(s*j+u))
```

導出：約数を d = s\*j+u、相方を m/d = s\*i+u'（i, j >= 0）と書く。d\*(m/d) = s\*n-t を n について解くと

n = s\*i\*j + u\*i + u'\*j + q

となる。2行目は i について、3行目は j について先に等比級数の和をとったもの。

- u と u' を入れ替えても同じ式なので、相方の数列（Also の組）の G.f. は一致する。
- OEIS の G.f. は k = j+1 とおき直した形 Sum_{k>0} x^(u\*k-(u-q))/(1 - x^(s\*k-(s-u'))) で書かれている。46 件の G.f. はすべてこの 2 つの形（u' = u のときは 1 つ）。
- gcd(u, s) > 1 のときは u' が一つに決まらない。u\*u' ≡ -t (mod s) をみたすすべての u' について上の和を足せばよい（「別の名前で登録されているもの」の 6 件で確認）。

例：A363852（s = 7, t = 5, u = 1）では u' = 2, q = (2+5)/7 = 1 なので

```
Sum_{j>=0} x^(j+1)/(1 - x^(7*j+2)) = Sum_{j>=0} x^(2*j+1)/(1 - x^(7*j+1))
```

k = j+1 とおくと OEIS の Sum_{k>0} x^k/(1 - x^(7\*k-5)) と Sum_{k>0} x^(2\*k-1)/(1 - x^(7\*k-6)) になる。
